# Нэнсик — Большой побег

Солнечный городской раннер с тремя полосами, поездами, барьерами, монетами и реалистичной полосатой кошкой. Окружение вдохновлено яркими городскими раннерами вроде Subway Surfers; графика окружения и интерфейс оригинальные, без ассетов или логотипов той игры.

Перспективное **2.5D-окружение на Canvas**, кошка — восемь фотографически реалистичных кадров бега и отдельная поза пригибания. Это не полноценная скелетная 3D-модель. Окрас и телосложение опираются на исходное `cat.png`; исходное фото сохранено без изменения.

## Запуск

Нужен Node.js 20 или новее. Внешних npm-зависимостей нет.

```bash
git clone https://github.com/amba-pro/Nensik.git
cd Nensik
npm start
```

Открыть **http://127.0.0.1:5173**. Не открывайте `index.html` двойным щелчком: ES-модулям нужен HTTP-сервер. Команды одинаковы для Windows PowerShell, Linux и macOS.

Если порт занят:

```bash
npm start -- --port 5174
```

Остановить: `Ctrl+C`. После скачивания игра работает без Интернета: шрифты системные, графика локальная, звук синтезируется браузером. По умолчанию звук выключен.

## Управление

| Действие | Клавиатура | Телефон |
| --- | --- | --- |
| Смена полосы | ← / → или A / D | Свайп влево / вправо, кнопки |
| Прыжок через барьер | ↑ / W / пробел | Свайп вверх или короткое касание |
| Пригнуться под знаком | ↓ / S | Свайп вниз или кнопка |
| Пауза / продолжить | P / Escape | Кнопка Ⅱ |
| Начать / повторить | Пробел / Enter или кнопка | Кнопка |

Поезда нужно обходить: перепрыгнуть поезд нельзя, его бок тоже препятствие. В каждом ряду есть свободная полоса, отмеченная монетами. При уходе с вкладки игра ставится на паузу. Рекорд хранится локально; ограничения localStorage не мешают запуску.

## Проверка

```bash
npm run check
npm test
```

Тесты проверяют смену полос, прыжок, пригибание, столкновение с поездом и его боком, сбор монет, 1000 генерируемых рядов, паузу, перезапуск и предел скорости.

В этой среде синтаксис, симуляция и HTTP-проверки выполнены. Полная визуальная браузерная приёмка пока **не выполнена**: установка локального Chromium не завершилась, облачный браузер отклонил доступ к локальному адресу. При запуске в Cursor проверьте desktop/mobile, анимацию и управление (см. `docs/CURSOR_START.md`).

## Файлы

- `index.html`, `style.css` — интерфейс и адаптивная раскладка.
- `game.js` — перспектива, отрисовка города, кошки, управление, звук.
- `core.js` — независимая игровая симуляция.
- `assets/cat-run.png` — прозрачный атлас 4 × 2, 8 кадров.
- `assets/cat-duck.png` — отдельная натуральная поза, без деформации спрайта.
- `cat.png` — исходный референс.
- `server.mjs` — локальный сервер, отдающий только файлы игры.
- `tests/` — проверки на встроенном `node:test`.
